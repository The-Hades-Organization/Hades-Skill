Sem conexão com o Hades

Este aparelho não alcança o painel agora. O painel só mostra dados ao vivo, então não fica uma cópia antiga para ler.

O que conferir

  • O ambiente está no ar? No terminal da máquina: /hades env status.
  • Pelo celular, o túnel precisa estar aberto (página Acesso remoto, quando voltar).
  • A rede deste aparelho está ligada?

A página tenta sozinha quando a rede voltar.
